# Sistema de Agentes de IA para Desarrollo de Proyectos

## Objetivo

Establecer un flujo de trabajo simple y efectivo usando agentes de IA
para mejorar la organización, innovación y desarrollo de proyectos.

## Contexto

El usuario trabaja principalmente en proyectos de software o mixtos, con
duración de días a meses, frecuentemente en frontend. Su principal
problema es la desorganización y bloqueos técnicos.

## Ideas clave

-   Usar pocos agentes (3) para evitar complejidad
-   Seguir un flujo claro: Planificar → Diseñar → Desarrollar
-   No mezclar roles en un mismo proceso
-   Guardar todo en un solo archivo

## Sistema de trabajo

### 1. Planificación

Actuar como project manager: - Definir objetivo - Dividir tareas (máx.
10-15) - Priorizar - Identificar riesgos

### 2. Diseño + Innovación

Actuar como arquitecto + investigador: - Definir estructura del
sistema - Elegir tecnologías - Proponer 2-3 ideas innovadoras

### 3. Desarrollo + Testing

Actuar como desarrollador + tester: - Implementar funcionalidades -
Detectar errores - Optimizar código

## Flujo

1.  Planificar
2.  Diseñar
3.  Desarrollar y probar

## Trabajo realizado

-   Definición de agentes clave
-   Simplificación del sistema
-   Creación de flujo adaptable a proyectos cortos y medianos

## Problemas / dudas

-   Tendencia a desorganización
-   Bloqueos técnicos frecuentes

## Conclusiones

Un sistema simple y consistente permite mejorar productividad y calidad
sin generar sobrecarga.
